## 为什么建站常常会推荐搬瓦工

国内用户搜VPS建站推荐，搬瓦工这个名字几乎绕不开。它的核心卖点不是"最便宜"，而是**针对中国方向做了线路优化**——也就是说，国内访问你网站的速度比同等价位的纯海外VPS要稳。

搬瓦工主要提供 CN2 GIA / CTGNet 线路的VPS。这是中国电信的高级IP转接网络，走 AS4809 / AS23764，专门用来解决普通国际线路在晚高峰丢包严重的问题。普通 163 网络（AS4134）高峰期丢包率可能飙到30%以上，CN2 GIA 在这种场景下的稳定性要好很多——这一点搬瓦工官方页面也明确说明过，并不是营销话术。

对建站来说，线路稳不等于一切，但如果你网站的访客主要在国内，一个晚高峰打不开的网站基本等于没建。这也是为什么很多建站教程会把搬瓦工列为"预算充足、重视国内直连速度"的备选。

但有几件事要提前知道：

- 搬瓦工是**自管型（self-managed）**VPS，没有官方的"帮你装WordPress"服务，你得自己会用命令行或面板部署网站环境。
- CN2 GIA 线路的成本不低，搬瓦工的 CN2 GIA 套餐比普通线路套餐贵不少，这是线路本身的成本决定的，不是商家乱定价。
- 如果你网站用户主要在欧美，CN2 GIA 对你没什么意义，反而应该选机房离用户更近的普通VPS。

## 建站到底选哪个套餐

不同建站场景对应的配置差别很大，没必要一开始就买顶配。

**个人博客 / 练手 / 测试站**

如果只是想跑个 WordPress 博客、记笔记、或者学习 Linux，1GB 内存起步就够用。Basic 系列的 20G KVM（$49.99/年）是搬瓦工最便宜的入门款，普通线路、1Gbps、1TB 流量，跑个低流量博客没压力。它的缺点是没有 CN2 GIA 优化，国内晚高峰访问可能不太稳。如果不在意国内访问速度，纯粹练手或面向海外访客，这个套餐够用。

**面向国内访客的内容站 / 企业展示站**

访客在国内、又想要稳定的访问体验，建议直接上 CN2 GIA-E 系列。最低配的 20G CN2 GIA-E（$49.99/季，约 $169.99/年）配置和 Basic 20G 一样，但走的是 CN2 GIA 线路、带宽升到 2.5Gbps，国内访问稳定性明显好一个档次。多花的钱主要是为线路买单。

1GB 内存跑 WordPress 没问题，但要稍微注意 PHP 和 MySQL 的内存配置，最好开 OPcache 之类的缓存。流量上来后或者装了比较多插件，再考虑升到 40G（2GB 内存）那一档。

**外贸独立站 / 电商站**

外贸站的访客一般在海外，机房选离目标市场近的就行——美国客户选洛杉矶，欧洲客户选阿姆斯特丹，亚太客户可以看东京。CN2 GIA 对外贸站意义不大，因为你的访客根本不在国内。这种情况下，选 Basic 系列的 80G 或 160G 反而更划算，把预算花在配置和带宽上比花在线路上更合理。

如果网站涉及在线交易、对宕机容忍度很低，再考虑 SLA 系列。$65.89/季度的 20G SLA 比 CN2 GIA-E 20G 贵 $15.9/季度，多出来的是 99.99% 在线率承诺和每两周一次免费换 IP，外加独享 AMD CPU。这个差价对正式业务站来说不算贵，但对你如果只是跑个普通博客，就没什么必要。

**对国内访问延迟敏感的应用**

如果你跑的是远程办公、视频会议、对国内响应速度要求极高的应用，那才需要考虑 Ultra 系列的香港或东京 CN2 GIA。$89.99/月起步，年付接近 $900，比 E-Commerce 贵一个数量级。普通建站没必要碰。

## 用搬瓦工建站的实际流程

确认了套餐，建站本身大致分几步：

1. **买VPS**：选套餐、选机房、选计费周期（季度、半年、年度），付款后几分钟内开通。搬瓦工支持支付宝、信用卡、PayPal 等方式。
2. **域名解析**：买好域名后，把 A 记录指向 VPS 的 IP 地址。
3. **装系统**：搬瓦工用自研的 KiwiVM 面板管理，开机后可以从 AlmaLinux、RockyLinux、Debian、Ubuntu、CentOS Stream 等模板里选一个一键安装。Debian 和 Ubuntu 对新手相对友好。
4. **部署 Web 环境**：两种主流方式——命令行装 LNMP/LAMP 一键包，或者装宝塔面板、1Panel 这类可视化面板。新手推荐面板，省去记命令的麻烦。
5. **装 WordPress**：环境配好后，下载 WordPress、配置数据库、跑安装向导，10 分钟内能完成。
6. **加缓存、配 SSL、做备份**：WordPress 自身不快，加 WP Super Cache 或 W3 Total Cache 这类缓存插件能显著提升响应。SSL 用 Let's Encrypt 免费证书，搬瓦工的 KiwiVM 也支持快照备份。

> 搬瓦工的服务是 self-managed，意思是服务器层面的事都得你自己处理。如果你完全不想碰命令行，Cloudways 这类托管型 WordPress 主机更适合你，但价格也更高。

## 常见疑问

**搬瓦工比 Vultr / RackNerd 好在哪？**

不在"好不好"，在线路定位。Vultr 机房多、按小时计费、配置灵活，但国内访问走的是普通国际线路，晚高峰不一定稳。RackNerd 价格低、活动多，适合练手和测试，但稳定性和国内访问速度都不算它的强项。搬瓦工的核心差异是 CN2 GIA 线路——如果你的访客在国内，这个差异就是实打实的体验差距。

**1GB 内存够跑 WordPress 吗？**

够，但要注意：禁用不必要的插件、开 OPcache、用轻量主题、定期清理数据库。1GB 跑 WordPress + MySQL 是能跑起来的，超过 1GB 的话升到 2GB 会更舒服，特别是装了 WooCommerce 或者主题比较重的情况。

**搬瓦工需要备案吗？**

不需要。海外 VPS 不在大陆境内，不涉及 ICP 备案。如果你的网站主要服务国内用户但又不想备案，海外 VPS + CN2 GIA 线路是一种折中方案。但要注意，不备案的网站在大陆境内的某些推广渠道（比如百度竞价）会受限，正规做国内业务还是建议老老实实备案。

**CN2 GIA 真的有那么神吗？**

CN2 GIA 的优势是相对的，不是绝对的。它比 163 和 CN2 GT 稳定，但也不是免疫一切的网络——遇到 DDoS 攻击时搬瓦工会做 IP nullrouting，那段时间访问会受影响。它解决的是"晚高峰丢包严重"这个具体问题，不是"国内访问永远快"的保证。

**SLA 99.99% 到底意味着什么？**

理论上每月宕机不超过约 4.4 分钟，超过会有补偿。但 SLA 是"在线率承诺"，不是"性能承诺"——你的网站能不能跑得快、流量够不够用、会不会因为插件问题变慢，这些都不在 SLA 范围内。SLA 适合对宕机容忍度极低的正式业务，对个人博客意义不大。
